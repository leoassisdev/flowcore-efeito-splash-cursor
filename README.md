## Como instalar

1. **Crie src/components/SplashCursor.tsx** Copie o conteúdo de `src/SplashCursor.tsx` deste repositório.
2. **Sem deps externas — WebGL puro**
3. **Use na página**

   ```tsx
   <SplashCursor COLOR="#3FB5FF" RAINBOW_MODE={false} />
   ```
